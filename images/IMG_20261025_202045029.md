Fun thing regarding the Arduino/the picture with the same name as this file

The ground wire must always be on the second pin up from the bottom

But the wires for the 3 rows of the light board must always be in the slots in the photo. If they are not the math making images display properly breaks and you end up with the photo being displayed wrong. So any future workers on this project, make sure the wires go in the pins in the image.
